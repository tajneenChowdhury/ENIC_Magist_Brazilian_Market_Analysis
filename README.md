# ENIC_Magist_Brazilian_Market_Analysis
# Data
This project analyzes the Magist Brazilian E-commerce dataset using SQL for data analysis and Tableau for visualization.
The dataset was provided by WBS Coding School.
Due to GitHub file size limitations, the large raw database dump files are not included in this repository.
# Files
magist_schema.sql — database schema structure

magist_schema_er.pdf — schema documentation or ER diagram
